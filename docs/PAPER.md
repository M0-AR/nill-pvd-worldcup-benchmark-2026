## 3. Method
### 3.1 Formalism
Impulse/Base/Decision with 3-touch gate; S1/S2/S3 with R floors; 1% risk; 5 bps + 0.05 ATR slip; next-open; stop-first intrabar; 60-bar time stop; 30%-partial→breakeven. All causal.
### 3.2 Validity
Expanding 4-fold WF; friction ladder 0/5/10/20; permutation 2000; year/regime splits; 5 benchmarks; metric set {CAGR, Sharpe, Sortino, Calmar, MaxDD, PF, expectancy, avgR, T}.
### 3.3 Data
Yahoo public: DAX ^GDAXI 1987–2026 (9802d + 2031×15m), WTI CL=F / ES ES=F / NQ NQ=F 2000–2026 (≈6570d + 4522×15m). Manifests in data/.

## 4. Results
Tables = README §6 (daily/intraday/WF/friction/benchmarks). Key: no T≥2, no perm-p<0.05, no year-stability. WTI-daily PF 1.27 is the sole nominal positive — insignificant (p 0.22) and WF-unstable.

## 5. Hidden patterns (H1–H5)
- H1 (small>large breakouts): UNTESTABLE under OHLC calibration (all-large artefact) — finding about measurement, not markets.
- H2 (long>short): SUPPORTED directionally (DAX longs +0.79R vs shorts −0.26R; WTI longs +0.53R vs shorts +0.01R) but N<100, post-hoc — needs pre-registered 15m + profile test.
- H3 (3-touch): enforced by design; placebo (2-touch) left for follow-up (code hook: base_valid_3t threshold).
- H4 (R≥3): friction ladder shows R≥3 necessary but insufficient; RR2 sensitivity yields same signs (checked).
- H5 (regime): covid vs post-2021 split significant visually; formal Chow/break test future work.

## 6. Discussion
Negative result is informative: bounds discretionary alpha to undisclosed geometry + profile/footprint + gating + experience. Parallels MNQ study. Survivorship of champions vs strategies: Nill survives via risk law, not win-rate.

## 7. Threats to validity
Proxy error (cash vs futures), short intraday window, single-position, no portfolio, cost approximations, multiple-comparison inflation in probes (reported as exploratory).
